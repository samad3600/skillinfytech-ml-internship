# SkillInfyTech ML Internship Projects

This repository contains projects completed during my Machine Learning Internship at SkillInfyTech.

## 🔹 Projects

### 1. Fake News Detection System
- NLP-based classification
- Uses TF-IDF + Logistic Regression
- Detects real vs fake news

### 2. VisionAI – Image Classification
- Deep Learning (CNN)
- Trained on CIFAR-10 dataset
- Predicts image categories

### 3. CineAI – Movie Recommendation System
- Content-based filtering
- Uses cosine similarity
- Integrated with TMDB API for posters

## 🚀 Technologies Used
- Python
- Machine Learning
- Deep Learning
- NLP
- Streamlit

## 📌 Outcome
Developed 3 real-world AI applications with interactive UI and deployment.
